# Tarot & Tea

Tarot reading app. The full product design lives in `docs/DESIGN.md`. Read it before building features and keep it updated when decisions change.

Must-haves: spreads where each position has a meaning and draw order fills positions in sequence; reversed cards; an in-app "How Tarot Works" guide explaining this.

This repo is public: never commit API keys or secrets (use `.env`, which is gitignored).
